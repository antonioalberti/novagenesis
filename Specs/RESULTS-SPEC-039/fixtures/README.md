# Synthetic shape fixtures — not runtime evidence

All 16 JSON files are hand-authored synthetic schema inputs. Names, PIDs, UIDs,
addresses, counts, paths, hashes and status values are illustrative placeholders;
no build, process, IPC operation or correctness run produced these files.
The filenames describe scenario labels, not validation or acceptance verdicts.
These are separate structural inputs, NOT a mutually hash-bound runtime bundle.
Observer arrays in pre-construction failure cases are empty, not fabricated starts.
Unavailable observations/provider identities use null, never a measured zero.

The run-record partial fixture is pending without common authority and has no
final failure claim. The mutation suite also exercises an evidence-only finalized
partial record with a synthetic authority-validation flag. That flag is necessary
shape metadata, NOT authentication or proof that a supervisor receipt is valid.

## Remaining contract gaps (SPEC-039 §9)

These schemas cannot close D2a: concrete observer sequence/delta, correlated
wait/decision records, bootstrap/drain equations and name/key/hello tuple are open.
The observer schema validates event shapes only, not lifecycle or reservation
journal replay. Normal cleanup resource identity/exclusivity and foreign-object
preservation require a concrete contract and executable cross-artifact verifier.
Provider schema describes available/unavailable identity only, not ELF symbol
binding or link-provider proof. Sticky errno/site fault capture (all three sites)
and ENOENT/EACCES/EMFILE fault injection remain open. Common-authority receipt
validation, supervisor-only lease ownership/continuous liveness, disjoint wait
sets, shutdown containment and 60-second budget enforcement remain open.
Artifact byte/hash consistency, missing-artifact reconciliation, run-ID/PID
cross-binding and real finalizer semantics are not checked by JSON Schema.
Historical assertion names are retained as shape fields, not an approved oracle.
No manifest/SPEC projections were changed; any embedded historical schema requires
separate reconciliation. Green structural tests grant no gate acceptance.
